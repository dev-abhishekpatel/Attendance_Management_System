# Office Attendance Management System

This project is a MERN stack attendance management system for office employees.

## Project Structure

- `backend/` - Express.js API server
- `frontend/` - React + Vite dashboard

## Tech Stack

- React.js
- Node.js + Express.js
- MongoDB
- JWT Authentication
- Socket.IO
- React Native / Expo (planned for mobile)

## Quick Start

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

## Default Backend URL

- http://localhost:5000

## Default Frontend URL

- http://localhost:5173

## Notes

This is the starter foundation for the office attendance system. You can extend it with employee management, attendance logic, leave approval, WFH, GPS, geofence, and biometric verification.
